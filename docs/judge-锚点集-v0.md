# 判官人工锚点集 v0（judge-anchor-v0）

> 状态：v0 类目登记——首个类目 F1 于 2026-09-06 从 EQ-Bench 失败类提炼入册。
> 代码侧登记：`src/declared/contract.ts` `JUDGE_ANCHOR_SET_V0`（类目表）+ `JudgeFingerprint.anchorSetV`（判官指纹必填字段）。
> 用途：判官上岗前逐类目施测、偏差入账（R3-16 第 4 条「人工锚点集定期校准判官偏差」的实体）。
> 铁律在案：**EQ-Bench 分数本身不追**——它的失败模式只用来提炼判官校准类目，不是分数目标。

## 使用方式

1. 判官候选（异构 panel，≥2 家族）对锚点集逐类目作答；
2. 与人工参考比对，逐类目记偏差（仪器事件，`instrument: true`，走 bench 轨）；
3. 偏差超阈的类目 = 该判官的禁用面（相应盲评题不给它上桌）；
4. 锚点集本身冻结版本号；加类目 = 升版本（judge-anchor-v1），已入账偏差不追溯混算。

## 类目

### F1 · 表面在场虚高（zero-presence inflation）

- **定义**：文本中出现某情绪的词汇/场景线索（提到愤怒的词、哭的画面），但线索不属于被判主体——属于对方、属于过去、属于反讽或转述——主体实际不持有该情绪。**0 分语义 = 该情绪在主体的真实内在状态中缺席：线索在场 ≠ 主体在场。**
- **来源**：EQ-Bench v2 首跑（doubao-seed-evolving，60 题）三题负分失败类的共同模式——参考答案 0 分的情绪被判官型模型打出 8–9 分（题 66/112/152：`ref=(0,8,0,6)→user=(9,6.5,0.5,3.5)` 等）。
- **测法**：锚点题为「线索在场但主体缺席」的对话；判官须给该情绪 ≤2/10（人类参考 0–1）。打 5 分以上 = F1 偏差阳性。
- **为什么判官必须测**：C_s 盲评判的是「回应与信号的内容关联性」——F1 阳性的判官会把「堆了情绪词但没接住对方」的回应读成高关联，谄媚（R3-16）从词汇层后门回流。此为单判官不可上岗的第三个理由（前两个：EA 面弱、文风谄媚偏好）。
